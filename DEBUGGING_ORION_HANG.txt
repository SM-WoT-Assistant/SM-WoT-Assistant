📊 РОЗБІЖНІСТЬ 3: FALLBACK МЕХАНІЗМ БУВ СЛАБКИЙ
──────────────────────────────────────────────

МІЙ КОД:
  try:
      proc.wait(timeout=60)
  except TimeoutExpired:
      proc.kill()
      os.system('taskkill /f /im PjOrion.exe')

ПРОБЛЕМА:
  • taskkill може не спрацювати, якщо Orion заблокований
  • PID процесу могу не знімутися коректно
  • Немаю способу ПЕРЕКОНАТИСЬ що процес дійсно завершився

ПОТРІБНО:
  • Більш агресивне убивання через psutil
  • PowerShell Start-Process -WindowStyle Hidden як основний метод
  • Многоступеневий fallback


═══════════════════════════════════════════════════════════════════════════════
ЧТО Я ТЕПЕР ЗМІНИВ:
═══════════════════════════════════════════════════════════════════════════════

1️⃣ ОСНОВНИЙ МЕТОД: PowerShell Start-Process -WindowStyle Hidden
   ────────────────────────────────────────────────────────────

   ps_cmd = f'Start-Process -FilePath "{orion_abs}" ' \
            f'-ArgumentList "--unpack-folder=\\"{abs_folder}\\"","--exit" ' \
            f'-NoNewWindow -Wait -WindowStyle Hidden'
   
   subprocess.run(["powershell", "-Command", ps_cmd], timeout=timeout_sec, ...)
   
   ЧОМУ ЦЕ КРАЩЕ:
   • -WindowStyle Hidden - ховає вікно ПОВНІСТЮ (у Windows kernel level)
   • -NoNewWindow - не запускає нову консоль
   • -Wait - чекає завершення перед повертанням
   • PowerShell повинна знищити процес при завершенні команди


2️⃣ FALLBACK: Оригінальна Popen з более значною перевіркою
   ────────────────────────────────────────────────────────

   if result.returncode not in (0, None):
       print("PowerShell таймаут, пробую fallback...")
   
   # Fallback: звичайний Popen з CREATE_NO_WINDOW
   # Але з більш агресивним убиванням процесу:
   
   try:
       import psutil
       for p in psutil.process_iter(['pid', 'name']):
           if p.info['name'] == 'PjOrion.exe':
               p.kill()  # ЦЕ НАСПРАВДІ ВБИВАЄ ПРОЦЕС
   except Exception:
       os.system('taskkill /f /im PjOrion.exe >nul 2>&1')


3️⃣ ЗМЕНШЕНІ ТАЙМАУТИ
   ────────────────

   Було: timeout_sec=60
   Стало: timeout_sec=30
   
   Батч по 24 файли декодуються ШВИДШЕ ніж хвилина,
   тому що Orion оптимізований для цього.
   Якщо батч завис на 30+ сек - це вже проблема.
