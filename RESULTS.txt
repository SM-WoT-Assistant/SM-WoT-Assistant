НАЛАШТУВАННЯ:
═══════════════════════════════════════════════════════════════════════════════

settings.json параметри:

  "pause_tank_auto_rebuild": true
    └─ true  = обновляє ЛИШЕ TTH (стабільний режим - за замовчуванням)
    └─ false = повний rebuild tank_db і tank_tth

  "tth_decode_retry_enabled": true
    └─ true  = при parse=0 автоматично запускає Orion (за замовчуванням)
    └─ false = пропускає авто-декод, використовує старий TTH

  "game_version": "v.X.X.X.X"
    └─ Встановлюється автоматично при оновленні
    └─ Можна змінити вручну для тестування

  "tth_schema_version": 2
    └─ Поточна версія схеми TTH
    └─ При змінах формату TTH - збільшується на 1

Ключові префікси у консолі:

  [INIT]     - ініціалізація при старті
  [HOTKEY]   - реєстрація гарячих клавіш
  [LOG]      - читання логів WoT
  [EXTRACTION] - витяг XML з game packages
  [DATABASE]   - парсинг і оновлення TTH
  [DECODER]    - запуск і прогрес Orion
  [SUCCESS]    - успішне завершення
  [ERROR]      - критичні помилки
  [WARN]       - попередження
