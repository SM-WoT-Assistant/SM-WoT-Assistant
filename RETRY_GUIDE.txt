ИНСТРУКЦИЯ ПОСЛЕ ИСПРАВЛЕНИЙ - ЗАПУСК ORION БЕЗ ЗАВИСАНИЯ
═══════════════════════════════════════════════════════════════════════════════

✅ ВИКОНУРИ ЗМІНИ:

1. Основний метод: PowerShell Start-Process -WindowStyle Hidden
   └─ Цей метод запускає Orion на kernel level без видимого вікна
   └─ Це єдиний надійний спосіб приховати Orion GUI

2. Fallback: psutil + taskkill з агресивним завершенням процесу
   └─ Якщо PowerShell не спрацює, вбивє Orion силою

3. Скорочені таймаути: 30 сек замість 60 сек на батч
   └─ Якщо батченія зави на 30 сек - це явна проблема, вбиття його

4. Двоступеневе убивання процесу:
   └─ psutil.process_iter() с kill()
   └─ taskkill /f /im PjOrion.exe як fallback


═══════════════════════════════════════════════════════════════════════════════
КРОК 1: ВБИЙТЕ ВСІХ СТАРИХ ORION ПРОЦЕСІВ
═══════════════════════════════════════════════════════════════════════════════

Відкріпте PowerShell (Windows + R, введіть "powershell", Enter)

Виконайте:
    taskkill /f /im PjOrion.exe

Скрін повинен показати:
    SUCCESS: The process "PjOrion.exe" with PID XXXX has been terminated.

ЯКШ ПОКАЗУЄ "ERROR: Не знайдено процесів" - це нормально, процеся не запущений.


═══════════════════════════════════════════════════════════════════════════════
КРОК 2: МОКУЙТЕ НОВУ ВЕРСІЮ (ЯК РАНІШЕ)
═══════════════════════════════════════════════════════════════════════════════

Відредагуйте файл settings.json (у папці проекту):

Старе:
    "game_version": " v.2.2.0.2 #859 ",
    "tth_schema_version": 2,

Нове:
    "game_version": "v.2.2.5.15",
    "tth_schema_version": 1,

ЗБЕРЕГТИ ФАЙЛ (Ctrl+S).

═══════════════════════════════════════════════════════════════════════════════
КРОК 4: ПЕРЕВІРТЕ РЕЗУЛЬТАТИ
═══════════════════════════════════════════════════════════════════════════════

Якщо програма завершилась:
    1. Запустіть UI поверх (Ctrl+C щоб зупинити консоль)
    2. Відкріпте AI STATS редактор
    3. Виберіть танк (наприклад, ІС-7)
    4. ДИВІТЬСЯ: TTH значення повинні бути видимі в одному стовпчику
       • Броня (HP)
       • Броня корпусу
       • Броня башти
       • Шкода
       • Пробиття
       • Перезарядка
       • Швидкість
       • Огляд

5. Перевірте tank_tth.json (відкніть файл у VS Code):
    • Розмір повинен бути ~309 KB (як раніше)
    • Записів повинно бути ~1264 танків
    • Поля: hp, speed_fwd, speed_bwd, hull_armor, turret_armor, view_range, reload, shells
