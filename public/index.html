SM WoT Assistant

Tactical assistant for World of Tanks — maps, tactics, AI builds

Download

Windows 10/11

Windows SmartScreen may warn about an unknown publisher. Click "Run anyway".

Features

SETUP

AI tank builds via Google Gemini. Equipment, perks, consumables — optimal choice for any vehicle.

MAPS

60+ in-game maps with 10×10 coordinate grid. All data from WoT client, no hardcoding.

TACTIC

Draw tactical schemes: markers, arrows, text, icons. JSON export/import. Clan publishing.

Overlay

Semi-transparent overlay window on top of the game. Auto-detection of map via python.log during battle.

How to update

The app automatically checks for new versions on startup. If an update is available, you'll see a notification in the status bar. You can also always download the latest version manually from GitHub.
