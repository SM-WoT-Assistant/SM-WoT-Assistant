## Що зроблено раніше (цього дня)

### 1. Збереження сторінки Tomato (tomato_selenium.py)
- Замість парсингу наживо - зберігаємо сторінку у файл
- Одразу закриваємо Chrome після збереження
- Парсимо локально (без Chrome)
- Тимчасовий файл видаляємо після парсингу

### 2. Lock для синхронізації (stats_ai.py)
- Додано `self._tomato_lock = threading.Lock()` в __init__
- fetch_and_update() тепер працює через lock
- Тільки одне вікно Chrome за раз

### 3. Видалено валідацію обладнання
- Видалено складну перевірку через client data
- Простий маппінг Tomato назв -> іконки

### 4. Безпечні перевірки для віджетів
- Додано try/except для уникнення TclError
