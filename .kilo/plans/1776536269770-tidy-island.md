# Plan: Оновлення назв мап з клієнту гри (українська локалізація)

## Мета
Дослідити механізм оновлення назв мап з клієнту гри на українській мові та спосіб співставлення технічних назв мап з локалізованими.

## Поточний стан (виявлено)

### 1. Джерело даних про мапи
- **МАНА І** (MAPS I): Завантаження з інтернету (map_updater.py)
- **МАНА ІІ** (MAPS II): Екстракція з клієнта гри (map_extractor.py)
  - Файли з `res/packages/scripts.pkg` клієнта гри
  - Розпаковуються в `extracted_maps/temp_xml/`
  - Декодуються через PjOrion (tools/orion/PjOrion.exe)

### 2. Технічні назви мап (id)
- Зберігаються в `extracted_maps/temp_xml/_list_.xml`
- Приклад: `01_karelia`, `02_malinovka`, `35_steppes` (65 мап)

### 3. Файл локалізації мап (ЗНАЙДЕНО!)
- **Шлях**: `C:/Games/World_of_Tanks_EU/res/text/lc_messages/arenas.mo`
- Це бінарний файл GNU gettext (.mo) з перекладами для мап
- Містить ключі типу `#arenas:01_karelia/name` з локалізованими назвами
- Працює для української мови (мова клієнта)

### 4. Поточний словник мап (проблема)
- `extracted_maps/map_dictionary.json` - словник "технічна назва → назва"
- Проблема: словник заповнений тільки технічними назвами (не українськими!)
- Приклад: `"01_karelia": "01_karelia"` замість `"01_karelia": "Карелія"`

### 5. Конвертація назв (поточна логіка)
- `config.TECH_MAPS_STAGING` - словник "технічна → англійська"
  - Приклад: `"01_karelia": "Karelia"`, `"35_steppes": "Steppes"`
- `locales.json` (секція `maps`) - словник "англійська → українська"
  - Приклад: `"Karelia": "Карелія"`, `"Steppes": "Степи"`

### 6. Проблема
- Тег `userString` у _list_.xml порожній (немає локалізації з клієнта)
- Система використовує статичний locales.json замість даних з клієнта

## Кроки для реалізації

### Крок 1: Розпарсити файл arenas.mo
- Знайти/створити Python бібліотеку для читання .mo файлів
- Популярні варіанти: `python-gettext`, вбудований `gettext`, або власний парсер
- Прочитати `C:/Games/World_of_Tanks_EU/res/text/lc_messages/arenas.mo`
- Отримати словник: `#arenas:01_karelia/name` → "Карелія"

### Крок 2: Модифікувати map_extractor.py
- Додати функцію читання `arenas.mo` з клієнта
- При оновленні мап створювати словник українських назв
- Зберігати у `extracted_maps/map_dictionary_ua.json`
- Пріоритет: клієнт → статичний locales.json

### Крок 3: Оновити locale_manager.py
- При роботі з МАПА ІІ використовувати словник з клієнта
- Додати метод для отримання українських назв з `arenas.mo`
- Зберігти сумісність з МАПА І (інтернет джерело)

### Крок 4: Тестування
- Перевірити оновлення мап з клієнта
- Перевірити відображення українських назв у інтерфейсі
- Перевірити нові мапи після оновлення гри

## Очікуваний результат
- Назви мап в інтерфейсі братимуться з клієнта гри українською мовою
- При оновленні клієнта гри назви мап автоматично оновлюватимуться
- Повна підтримка української локалізації
